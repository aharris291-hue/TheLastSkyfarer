# Firefly Prompts: Batch 1 (Milestone A)

How to use: in Adobe Firefly, choose one of **Adobe's own Firefly Image models**, not a partner model. Paste the style block and then one prompt. Generate 4 variations. Save the ones you like as PNG in the folder shown, inside the repo clone on your PC (`Unreal/SourceArt/Firefly/...`), and name them as shown (add `_v1`, `_v2` and so on). I pick them up from there and log each one in the asset manifest as AI-generated (Adobe Firefly).

Characters that already have turnarounds (Kieran, Piko, Elias, Tessa, Bram, Elara and others) are **not** redesigned. Their existing sheets are the reference.

## Style block (paste first, every time)

> Hand-painted storybook fantasy concept art, original design, soft painterly brushwork, warm natural light, gentle colour harmony, rounded friendly shapes, rich but simple detail, readable silhouettes, stylized not photoreal, clean composition, no text, no watermark, no logos.

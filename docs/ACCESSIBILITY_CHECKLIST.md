# Accessibility Checklist

| Item | State |
|---|---|
| Full keyboard and controller support, no mouse needed | Done |
| Remappable controls, saved between sessions | Done (keyboard tested; controller remap tested in code only) |
| Prompts show the current device's key or button | Done |
| Hold or toggle to glide | Done |
| Text size option (1.0x to 1.5x) | Done |
| Text speed including instant | Done |
| Separate volume for master, music, effects, ambience | Done |
| Screen shake toggle | Toggle exists; the demo has no screen shake yet |
| Subtitles: all speech is text (no voice acting) | Done |
| Important sounds have a visual cue (Piko glow and "!" for sensing, notifications) | Done |
| Pause anywhere during play | Done (not during an open dialogue box, which already waits for input) |
| Respawn without penalty on falls | Done |
| Colour-blind check of UI and markers | Not done |
| Screen reader support | Not planned for demo |
| Difficulty or assist options (e.g. slower fall) | Not done |
